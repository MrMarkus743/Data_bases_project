## Роли и принципы доступа

| Роль | Принцип доступа |
|---|---|
| `credit_analyst` | Видит банковскую тайну (скоринг, финансовые метрики), но ПДн маскированы. Нет доступа к аудиту. |
| `loan_operator` | Видит ПДн полностью (оформление договоров), видит финансовые поля, но не может менять скоринг/историю. |
| `system_auditor` | Доступ только к `audit_log`. |

## Матрица прав
Обозначения:

    S = SELECT, I = INSERT, U = UPDATE, D = DELETE

    S* = SELECT с маскированием ПДн-полей (см. раздел «Правила маскирования»)

    — = нет доступа

| Сущность (таблица) | Категория данных | Роль | Разрешённые операции | Запрещённые операции | Основание ограничения |
|---|---|---|---|---|---|
| `loan_purposes` | Открытые | `credit_analyst` | S | I, U, D | Справочник, ПДн нет; изменение - только администратором (бизнес-правило) |
| `loan_purposes` | Открытые | `loan_operator` | S | I, U, D | Справочник, ПДн нет; изменение - только администратором (бизнес-правило) |

| `clients` | ПДн | `loan_operator` | S, I, U | D | Ст. 6 152-ФЗ (обработка для оформления договора); ст. 5 - хранение, удаление по регламенту, не сотрудником |
