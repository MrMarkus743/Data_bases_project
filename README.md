# Database Systems Team Project

![Database](https://img.shields.io/badge/database-PostgreSQL%2016%2B-336791.svg)
![Python](https://img.shields.io/badge/python-3.10%2B-blue.svg)

> Командный проект по дисциплине «Базы данных». Проектирование реляционной модели данных (8+ сущностей, 3НФ), реализация серверной логики на PL/pgSQL, разграничение прав доступа (152-ФЗ), пакетная ETL-обработка данных на Python (1M+ записей) и профилирование запросов через EXPLAIN ANALYZE.

---

## 👥 Команда проекта и распределение ролей

- **Аналитик:** [Тимонина Виктория Дмитриевна](https://github.com/ProgCodTim) — Концептуальная и логическая модель данных, нормализация, карта данных (`data_map.md`), классификация по 152-ФЗ, аналитические SQL-запросы.
- **Администратор:** [Ковыров Денис Владимирович](https://github.com/dkovyaboba) — Серверная разработка на PL/pgSQL, триггеры валидации и аудит в JSONB, матрица и скрипты разграничения прав доступа (DCL, `roles.sql`).
- **Разработчик:** [Подлесных Марк Владимирович](https://github.com/MrMarkus743) — Клиентский уровень на Python, пакетная загрузка данных, контроль качества данных, оптимизация и замеры производительности (`EXPLAIN ANALYZE`).

---

## 🛠 Технологический стек

- **СУБД:** PostgreSQL 16+
- **Язык программирования:** Python 3.10+
- **Инструменты администрирования и среды:** DBeaver Community, Docker, Git

## 📂 Структура репозитория

```text
Data_bases_project/
├── docs/                            # Аналитическая и проектная документация
│   ├── analysis/
│   │   ├── access_matrix.md         # Матрица доступа и требования к защите данных
│   │   └── data_map.md              # Описание предметной области и карта данных (152-ФЗ)
│   ├── diagrams/                    # Каталог схем и ER-диаграмм
